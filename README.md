# Personal Finance Tracker (My Wallet) 💰

A simple and efficient Command-Line Interface (CLI) application to manage your daily expenses and income. This tool helps you track your savings and generates a sorted financial report.

## 🚀 Features
- **Income & Expense Tracking:** Log your financial activities easily.
- **Auto-Sorting:** Reports are automatically sorted by amount (highest to lowest).
- **Persistent Storage:** Saves your data in a `json` file so you don't lose it.
- **Currency Support:** Choose between LYD and USD.
- **Input Validation:** Prevents program crashes by ensuring numerical inputs are valid.

## 📂 File Structure
- `wallet.py`: The main application script.
- `wallet_data.json`: (Auto-generated) Stores your financial records.
